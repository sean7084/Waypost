{% trans "Common Filtering Parameters" %}

{% trans "Assets API supports the following query parameters:" %}

  • status - Filter by asset status (available, assigned, in_use, maintenance, etc.)
  • category - Filter by category ID
  • brand - Filter by brand ID
  • company - Filter by company ID
  • location - Filter by location ID
  • division - Filter by division ID
  • assigned_to - Filter by assigned user ID
  • barcode - Exact barcode match
  • search - Search across asset_number, serial_number, barcode
  • ordering - Order by field (e.g., -created_at, asset_number)
  • page - Pagination page number
